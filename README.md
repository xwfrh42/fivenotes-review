## 主要功能盘点

### 五个笔记页，底部圆点切换

五个页面用底部彩色圆点区分，点击切换，快捷键也行。想在某个页面临时记个颜色代码、电话号码、代办项——分门别类，清清爽爽。

而且有个细节挺实用：直接把文字**拖到底部圆点**上，就能把内容追加到对应页面，都不需要先把窗口显示出来。

### 多彩主题，还能自制

内置了一堆配色方案，官方还持续在线更新新主题。嫌不够，甚至提供了 ThemeEdit 免费工具，自己做主题也行。对于颜值敏感型选手来说这一点挺加分的。

### iCloud 同步 + 自动备份

FiveNotes 3 加了 iCloud 同步，你在 Mac 上记的东西，可以同步到 iPhone/iPad（不过手机版 FiveNotes Mobile 是单独收费的）。

自动备份这个功能也有，防止手滑把重要内容删掉追悔莫及。开发团队有个自嘲：世界上有两种人，一种做备份，一种将来会做备份——FiveNotes 帮你直接进入第一种。

### Markdown 支持 + 任务清单

支持 Markdown 格式化，加粗、高亮、代码块都行。3.0 版本新加的 checkbox 任务清单也挺好用，`⌘T` 一键插入，点击直接打勾，有一种奇特的完成感。

另外还支持颜色预览，你在笔记里写一个 `#47b433` 这样的 hex 色值，它会直接显示颜色色块，点击自动复制，设计师和开发者应该会很喜欢。

### 自动化集成能力

支持 Apple Shortcuts、AppleScript 和 URL API，可以接入快捷指令、配合其他应用做自动化操作。这部分对于爱折腾工作流的用户来说想象空间很大。

## 它适合谁？

- **程序员 / 设计师**：写个临时代码片段、记个颜色值、放个 todo，比什么都快
- **内容创作者**：脑子里冒出来的词句、灵感，随手抓住，不让它跑掉
- **会议 / 通话中**：不想打断手头工作，弹出来快速记个电话、名字、重点
- **学生党**：考前临时备忘、公式速查，悬浮在参考资料窗口上方看

不太适合的场景：如果你需要管理几十上百条笔记、需要富文本排版、或者习惯用笔记库做知识管理，FiveNotes 不是为此设计的。它的定位就是那张**随时在手边的便条纸**，不多也不少。
